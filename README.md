# 🤖 Amin AI

دستیار هوشمند فارسی با کلی قابلیت: گفتگو، ماشین‌حساب، ساخت عکس و گیف، آهنگ‌سازی،
فال حافظ، تعبیر خواب، چیستان، ترجمه، تبدیل تاریخ شمسی/میلادی و ...

## اجرا

```bash
pip install -r requirements.txt
python server.py
```

بعد برو به `http://localhost:5000`

## تنظیمات (متغیرهای محیطی)

| متغیر | توضیح |
|---|---|
| `AMIN_SECRET_KEY` | کلید امنیتی نشست‌ها (حتماً یه مقدار تصادفی و طولانی بذار) |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | اختیاری — برای ورود با گوگل |

## نکته‌ی امنیتی

فایل‌های `users.json`، `conversations.json` و `user_memory.json` اطلاعات خصوصی کاربران رو
نگه می‌دارن و عمداً داخل `.gitignore` هستن. برنامه خودش موقع اجرا می‌سازدشون.
